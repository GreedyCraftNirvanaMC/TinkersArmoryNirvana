# 匠魂护甲：涅槃

将 **AntiqueArmory / Construct's Armory** 移植至 **Minecraft 1.21.1 + NeoForge 21.1.265+**，依赖 **TinkersNirvana 1.21.1-1.0.1+**。沿用 `conarm` 模组 ID 与内容命名空间，采用 **LGPL-3.0-or-later**。

[English](README.md) · [附属开发文档](docs/zh-CN/API.md) · [KubeJS 魔改文档](docs/zh-CN/KUBEJS.md) · [配置说明](docs/zh-CN/CONFIGURATION.md) · [材料表](docs/MATERIALS.md) · [验证与手动验收](docs/VERIFICATION.md) · [许可与署名](NOTICE.md)

包含四件模块化护甲、七种材质部件、原版三十种护甲材料数值、护甲词条与强化、组装、修复、部件替换、抛光、浮雕、装甲装配台和锻造台、冶炼炉浇筑，以及旅行腰带、药水腰带、背包、护目镜和披风。护甲损坏后保留物品，可以修复。配件库存保存在所属护甲的数据组件中。穿戴模型、配件模型与贴图沿用原项目资源并适配新版渲染接口。

打开手册封面后进入章节目录。材料、词条、强化和配件均有可点击的索引，支持物品提示与相关页面跳转；强化配方图读取当前世界的数据包／KubeJS 配方。可用书页箭头、滚轮或左右方向键翻页，Home 返回目录，Backspace 返回跳转前的位置。当前客户端会话内记住阅读位置，长内容自动续页。

## 安装

使用 Java 21、Minecraft 1.21.1 与 NeoForge 21.1.265 或更新的 21.1 版本。客户端和服务端均需安装 TinkersNirvana 与本模组的运行 JAR；不要把 `-sources.jar` 放进 `mods`。1.12 的 Forge、TinkersAntique、Mantle JAR 不能在本版本加载。

KubeJS 可选，已针对 `2101.7.2-build.381` 验证。使用时还需安装 KubeJS 声明的依赖，并保持客户端与服务端的启动脚本一致。不装 KubeJS 也可以正常加载本模组。

按照本次移植范围，JEI 暂缓：提供的 TinkersNirvana 尚无 JEI 集成实现。旧版 CraftTweaker／ContentTweaker 能力通过 Java API 和 KubeJS 接口承接。原先可选的 Tool Leveling 功能提供原生配置实现，默认关闭，不强制新增依赖。

## 基本使用

1. 用工作台与四个匠魂空白模具合成装甲装配台。将一个空白模具放进合成栏，转换为护甲模具。手持护甲模具右键切换目标部件，潜行右键反向切换。
2. 首格放护甲模具，其余格放可直接加工的原料。核心消耗分别为：头盔 4、胸甲 6、护腿 5、靴子 4 份材料；护甲板 3、夹板 1、抛光磨具 2 份。模具不消耗；可表示的材料余量以匠魂碎片返还。
3. 上排依次放入核心、护甲板、夹板即可组装护甲，三者允许使用不同材料。金属等可浇筑材料使用 TinkersNirvana 的冶炼炉；在部件上浇注金或铝黄铜获得可重复使用的铸模，也支持依赖配置控制的一次性黏土铸模。
4. 首格放护甲，后续格放核心材料或同材质抛光磨具进行修复；放新部件可替换对应部件；放强化材料可强化。装配台的文本框用于命名产物。3×3 合成栏也支持抛光磨具修复。
5. 升级成装甲锻造台后可使用六个输入格。抛光依次投入护甲、抛光磨具、沙子。浮雕依次投入护甲、目标部件、绿／蓝／熔岩史莱姆结晶、金块，每件护甲仅可浮雕一次。
6. 安装旅行配件后，默认按 **G** 打开配件控制。只有已安装且未损坏的装备可以操作，可交换腰带快捷栏、打开背包或药水腰带、切换护目镜与披风。如果与其他模组冲突，可在按键设置中修改。

每件护甲只能安装一个旅行配件。三种手套仅用于胸甲且互斥；高步、发光与冰霜行者仅用于靴子；水下呼吸强化仅用于头盔。不同抗性类型互斥，同类型抗性只有首次安装占用强化槽。游戏内宝典会显示当前材料与强化定义，也包含附属内容。

本版本在装甲装配台／锻造台加工护甲模具，不直接扩展依赖的部件加工台界面。匠魂原生工具装配台的加工模式也支持已有模块护甲与护甲模具；材料原料匹配和冶炼系统与 TinkersNirvana 共用。

## 构建

先构建 TinkersNirvana，再通过 `tinkersNirvanaJar` 指定依赖 JAR。默认查找相邻项目下的 `build/libs/TinkersNirvana-1.21.1-1.0.1.jar`。

```powershell
$env:JAVA_HOME = 'C:\你的\JDK21\目录'
.\gradlew.bat build '-PtinkersNirvanaJar=C:/实际路径/TinkersNirvana-1.21.1-1.0.1.jar'
```

产物位于 `build/libs/`，包含运行 JAR 与源码 JAR。`-PwithKubeJS` 可以在开发运行配置中加载 KubeJS。仓库不提交依赖二进制或游戏测试世界。完整开发约定与魔改示例见上方文档。

此移植不提供 1.12 附属的二进制兼容，也不自动转换 1.12 世界和物品 NBT。护甲防护通过 1.21 原生护甲、属性和伤害事件实现；旧版 `ISpecialArmor` 与脚本需要迁移。
